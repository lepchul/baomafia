# 🐱 Bao Mafia — телеграм-бот для игры в мафию в группах

Мафия по мотивам Баограда — города, где живут около 2500 котов и завелась мафия.

---

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN от @BotFather
python main.py
```

Нужен Python 3.10+.

### Что настроить у @BotFather

1. `/setprivacy` → **Disable** — иначе бот не увидит обычные сообщения в группе
   и не сможет удалять сообщения неиграющих.
2. Бота добавляют в группу и выдают права: **удаление сообщений** и **закрепление сообщений**.

## Команды

| Команда      | Где           | Кто            | Что делает                          |
|--------------|---------------|----------------|-------------------------------------|
| `/newgame`   | группа        | только админы  | новая игра, открывает регистрацию   |
| `/startgame` | группа        | только админы  | окончить регистрацию и начать игру  |
| `/stop`      | группа        | только админы  | окончание игры                      |
| `/leave`     | группа/личка  | все            | выйти из игры (во время регистрации) |
| `/shop`      | **только личка** | все         | магазин за Baocoin'ы                |
| `/profile`   | личка         | все            | баланс, статистика, инвентарь       |
| `/roles`     | везде         | все            | список всех ролей                   |
| `/help`      | везде         | все            | справка                             |

Список подсказывается автоматически при вводе `/` — команды зарегистрированы
отдельно для лички и для групп.

## Как идёт игра

1. Админ пишет `/newgame` — в чат уходит закреплённое сообщение
   «Идет новая игра / Присоединились: …» с кнопкой **🎮 Присоединиться**.
2. Кнопка ведёт в личку бота, там игрок получает
   «Вы присоединились к игре в «название чата»».
3. Через 90 секунд (или по `/startgame`) регистрация закрывается,
   роли рассылаются в личку. Минимум — 4 человека.
4. **Ночь** — «🌕 Город засыпает, просыпается мафия…», роли ходят кнопками в личке.
5. **Утро** — «Сегодня был убит X, он был(а) роль».
6. **День** — обсуждение, затем голосование кнопками прямо в чате.
7. Повторяется, пока кто-то не победит.

### Порядок в чате

Пока идёт игра, бот удаляет:

* любые сообщения **ночью**;
* сообщения тех, кто **не участвует** в игре;
* сообщения **мёртвых** игроков.

Причину бот пишет автору в личку, чтобы не засорять чат. Команды не удаляются.

## Роли

**🏘 Мирный город**

| Роль | Что делает |
|------|-----------|
| 🐱 Мирный | просто вычисляет мафию на дневном голосовании |
| 🕵️ Комиссар Каттани | ночью **проверяет** или **стреляет**; бывают поддельные документы |
| 🩺 Доктор | лечит одного игрока — спасает от мафии и маньяка |
| 💋 Любовница | приходит к игроку ночью; если его убьёт мафия — умирает и она |
| 💣 Камикадзе | если его убьёт мафия или комиссар — убийца умирает вместе с ним (из мафии гибнет только один) |
| 🎖 Мэр | голос считается за два; появляется с 15 игроков и всегда ровно один |
| 📰 Журналист | ночью выбирает двоих и узнаёт, в одной ли они команде |
| 🚔 Сержант | получает значок комиссара, если тот погибнет |
| 👵 Бабуля с окна | узнаёт, сколько котов наведалось ночью к выбранному дому |

**🕶 Мафия**

| Роль | Что делает |
|------|-----------|
| 🎩 Дон | глава мафии, решающий голос при споре внутри команды |
| 🕶 Мафия | помощник Дона |

**🔪 Сам по себе**

| Роль | Что делает |
|------|-----------|
| 🔪 Маньяк | убивает по ночам, не относится к мафии, побеждает только последним |

Мафия и комиссар есть всегда, доктор — с 5 игроков.
Камикадзе, Любовница, Маньяк, Журналист, Сержант и Бабуля — **редкие**:
выпадают с шансом 20–30 % и только начиная с определённого числа игроков
(настраивается в `mafia/roles.py`, словарь `RARE_ROLES`).

## Экономика и магазин

За победу — **10–15 Baocoin'ов** (💎). Магазин открывается кнопкой в `/start`
или командой `/shop` (только в личке).

| Товар | Цена | Описание |
|-------|------|----------|
| 🔪 Нож | 100 💎 | Убить абсолютно любого в любое время, 1 раз за раунд. Мафии использовать нельзя. |
| 🎭 Прикрытие | 120 💎 | Проверка комиссара покажет, что вы мирный. Работает только когда вы мафия. |
| 👻 Голосование за умершего | 50 💎 | Голосовать даже будучи мёртвым. Не работает на мафию. |

Как это работает в игре:

* **Нож и Прикрытие** предлагаются в личке сразу после раздачи ролей —
  бот спрашивает, не хотите ли использовать их в этой игре.
  Нож не предложат мафии, Прикрытие — не мафии.
* **Голосование за умершего** предлагается в момент смерти — и только если
  игрок не за мафию и погиб от рук мафии либо на голосовании.
* Предмет списывается со счёта в момент активации.

## Структура проекта

```
main.py                  запуск бота
mafia/
  config.py              токен, тайминги, товары магазина
  database.py            SQLite: баланс, инвентарь, статистика
  roles.py               все роли и раздача (в т.ч. редкие)
  texts.py               все тексты в одном месте
  keyboards.py           инлайн-клавиатуры
  game.py                движок: фазы, ночь, голосование, победа
  handlers/
    private.py           /start, магазин, профиль, вход по кнопке
    group.py             /newgame, /startgame, /stop, /leave
    game_cb.py           ночные действия, нож, предметы, голосование
    moderation.py        удаление сообщений
```

## Тайминги

Правятся в `.env`:

```
REGISTRATION_TIME=90
NIGHT_TIME=60
DAY_TIME=90
VOTE_TIME=45
```

Ночь и голосование заканчиваются раньше, если все успели сходить.
